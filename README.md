# KREID COUTURE — Luxury Pakistani Fashion & E-Commerce Platform

KREID COUTURE is an enterprise-grade Pakistani e-commerce platform and administrative control suite designed for luxury footwear (Air Jordan 1, AJ4 BIKE AIR, Off-White Chicago), vintage wide-leg baggy denim trousers, heavyweight streetwear tees, and tactical cargo pants.

## Features
- **Pakistani Payment Methods**: Cash on Delivery (COD), JazzCash, EasyPaisa, SadaPay/NayaPay, and Pakistani Bank Transfers with live account details and Payment Proof Screenshot upload.
- **Logistics Integration**: Integrated tracking simulation for TCS Express, Trax Logistics, and Leopards Courier.
- **Wishlist & Favorites Modal**: Save items across shopping sessions.
- **Admin Control Suite (`/#admin-kreid`)**: Executive overview with 24-hour live sales graph, live stock management, modal product editor with local image file uploader, coupon manager, and printable consignment dispatch slips.

## Access
- **Storefront**: `http://localhost:8080`
- **Admin Panel**: `http://localhost:8080/#admin-kreid`
